L'atelier

Une pâtisserie pensée pour votre événement

Caliza est un atelier artisanal belge basé à Wauthier-Braine, dans l'entité de Braine-le-Château. Chaque gâteau (anniversaire, pièce montée de mariage ou entremets) est conçu à la main, en fonction de vos envies : saveurs, couleurs, thème, texture, contraintes alimentaires.

Il n'existe pas de menu à prix fixe : après un échange par téléphone, nous définissons ensemble le type de pâtisserie, le nombre de parts et la personnalisation souhaitée pour construire un devis qui vous correspond.

Comment se passe une commande ?

  1. Vous décrivez votre idée dans le formulaire (ou vous vous inspirez de la galerie).
  2. Votre note est envoyée à Caliza via WhatsApp ou par téléphone.
  3. Nous échangeons pour affiner le thème, les saveurs et le nombre de parts.
  4. Vous recevez un devis personnalisé, sans engagement.
